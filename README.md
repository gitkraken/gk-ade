# GitKraken ADE

This is the public issue tracker for **GitKraken's ADE** (Agentic Development Environment), currently developed under the codename **Kepler**.

## What this repo is for

This repository is where we collect and track bug reports and feature requests for GitKraken's ADE.

This is not the source repository for the product — it exists purely as a public issue tracker and a place for the community to submit feature requests and bug reports.

## Filing an issue

If you've found a bug or have a feature idea, open a new issue on the [Issues](../../issues) tab.

Before filing, please read [CONTRIBUTING.md](./CONTRIBUTING.md) — it covers what to include in a report and how to check for duplicates.

Thanks for contributing!
